# Scripts

The working archive contains several generations of scripts used to download, deduplicate, compare and summarise TEC Register snapshots.

Before publishing them here, the scripts are being reviewed so the repository contains the current methodology rather than every experimental version.

Planned components:

- snapshot downloader / archive integrity check
- project-level deduplication analysis
- snapshot-to-snapshot comparison
- chart-data preparation

The original working scripts were developed with substantial AI assistance. See [../methodology/AI_ASSISTANCE.md](../methodology/AI_ASSISTANCE.md).
