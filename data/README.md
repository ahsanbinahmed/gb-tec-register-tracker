# Data

The local working archive contains date-stamped NESO TEC Register snapshots beginning on 9 August 2026.

The public repository will not automatically mirror every raw daily snapshot. Data will be included selectively where it improves reproducibility and where redistribution is appropriate.

For authoritative current data, use NESO's published TEC Register.

Historical findings in this repository should always be interpreted as observations from the archived snapshots available to the project at the time.
