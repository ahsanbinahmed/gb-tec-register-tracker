# Weekly Updates

This folder contains the **public** weekly TEC Register change summaries.

The underlying archive began in August 2026, but the August raw snapshots and derived historical analysis are intentionally retained privately. Public reporting begins with September 2026.

Each update compares snapshots approximately seven days apart and distinguishes project-level gate transitions from the MW actually attached to Gate 2 rows for staged projects.

- [15–22 September](2026-09-15_to_2026-09-22.md)

These summaries report changes observed in the archived NESO TEC Register. They do not by themselves establish why a project's gate, date or register status changed.
